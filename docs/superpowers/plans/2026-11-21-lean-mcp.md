# Lean ARM MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Implement the three core lean-server changes from the supplied specification on current ARM MCP plus PR #294.

**Architecture:** Keep retrieval selection and ranking untouched. Apply output slimming at the MCP presentation boundary, retaining the shared library's existing public response contract. Put the offline Learning Path index and rendering in a focused server utility, initialized once from SEARCH_RESOURCES.metadata. Reuse existing parent-text reassembly when rows are embedding pieces.

**Tech Stack:** Python 3.12, FastMCP 3.x, pytest, existing offline search resources.

**Spec:** docs/superpowers/specs/2026-11-21-lean-mcp-source.txt (Changes 1–3; optional Change 4 excluded unless requested).

## Global Constraints

- Base: PR #294 0c249c8cea1f79de56ea0a9b9541b052176ebe05, containing latest main 10ac34d853b85d089d936bda2efd9d6041fa2f6c.
- Retrieval (embedding, ranking, k, filters, scope) is NOT changed.
- Preserve PR #294 array-valued doc_type/product/platform and removal of edition. Preserve context, page_url, parent_page_url, and any other existing extra response keys.
- Preserve all existing citation URLs exactly, including query parameters and fragments.
- Preserve ARM_CONTENT_DISCLAIMER and UTM_SOURCE_PRESERVATION_NOTE wording in server instructions, with the behavioral rule first; total <= 4,096 characters.
- No network in get_learning_path. MAX_CHARS = 80000. Support full, commands, outline, optional page, invocation_reason.
- Match root on URL with query/fragment removed, anchored https://learn.arm.com/learning-paths/<category>/<slug>/; normalize missing trailing slash for lookup only.
- Use document_context.chunk_index or top-level chunk_index when present, otherwise specified heading heuristic. Reassemble/deduplicate embedding pieces so whole chunks appear once. Use stored page ordering when available, version fallback otherwise.
- commands mode text contains only extracted fenced blocks and sudo/export/$ shell lines, without duplicated shell lines already in fences. Citation context remains available in response fields/note.
- Optional playbook is a separate execution use case; core changes are the authorized default.
